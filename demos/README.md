## Status labels

- **Live:** running for a real client, with their permission to show it.
- **Demo:** a working, scripted scenario you can listen to or try.
- **Planned:** designed but not built yet.

## Adding a demo

1. Copy `demos/_template/` to `demos/<short-name>/`.
2. Fill in the README: scenario, call flow, outcome, tech and links.
3. Put the recording in `assets/` (or link to it) and add the transcript.
4. Update the tables here and in the root README, and change the status from Planned.
